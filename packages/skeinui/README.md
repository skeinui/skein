# skeinui

**English** | [简体中文](README.zh-CN.md)

An alias of the [Skein UI](https://github.com/skeinui/skein) `skein` command: `npx skeinui …` is the same as `npx @skeinui/cli …`.

> Looking for the components? They are [@skeinui/ui](https://www.npmjs.com/package/@skeinui/ui): `npm install @skeinui/ui @skeinui/themes`.

```bash
# a new project (or: npm create skein)
npx skeinui create my-app --template admin
# component docs
npx skeinui docs Button
# templates, features, theme styles
npx skeinui list
```

Inside a project, use the `skein` command it already has (`npx skein new page orders`). Every command: [@skeinui/cli](https://www.npmjs.com/package/@skeinui/cli).

| Package                                                          | What                              |
| ---------------------------------------------------------------- | --------------------------------- |
| [@skeinui/ui](https://www.npmjs.com/package/@skeinui/ui)         | The React components              |
| [@skeinui/themes](https://www.npmjs.com/package/@skeinui/themes) | Theme styles                      |
| [@skeinui/cli](https://www.npmjs.com/package/@skeinui/cli)       | The `skein` command               |
| [create-skein](https://www.npmjs.com/package/create-skein)       | `npm create skein`: a new project |
