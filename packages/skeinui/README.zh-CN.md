# skeinui

[English](README.md) | **简体中文**

[Skein UI](https://github.com/skeinui/skein) `skein` 命令的别名：`npx skeinui …` 等同于 `npx @skeinui/cli …`。

> 要找组件库？组件库是 [@skeinui/ui](https://www.npmjs.com/package/@skeinui/ui)：`npm install @skeinui/ui @skeinui/themes`。

```bash
# 新建项目（也可以用 npm create skein）
npx skeinui create my-app --template admin
# 组件文档
npx skeinui docs Button
# 模板、功能、主题风格
npx skeinui list
```

在项目里请直接用项目自带的 `skein` 命令（`npx skein new page orders`）。全部命令见 [@skeinui/cli](https://www.npmjs.com/package/@skeinui/cli)。

| 包                                                               | 内容                         |
| ---------------------------------------------------------------- | ---------------------------- |
| [@skeinui/ui](https://www.npmjs.com/package/@skeinui/ui)         | React 组件                   |
| [@skeinui/themes](https://www.npmjs.com/package/@skeinui/themes) | 主题风格                     |
| [@skeinui/cli](https://www.npmjs.com/package/@skeinui/cli)       | `skein` 命令                 |
| [create-skein](https://www.npmjs.com/package/create-skein)       | `npm create skein`：新建项目 |
